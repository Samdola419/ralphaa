# R Alpha Agent

Complete R Alpha UI (presets, thinking, prompts, Dahl / Token Harbor APIs) with agent tools.

## What it keeps
- Exact R Alpha UI and mascot
- Thinking states and effort
- Presets and API keys (Dahl, Token Harbor)
- Existing prompts and Firecrawl search
- Base prompts unchanged

## What it adds
- Multi-step agent tools: `search`, `fetch_page`, `run_code`
- **Site creation skills** (only active when building a site / UI / animation):
  - Motion official skill principles (Motion / Framer Motion best practices)
  - motion-anything style (intent-based, restrained motion recipes)
- Skills are injected only when the message looks like a site or interface request

## Deploy
1. Upload this folder (or the zip contents) to a new GitHub repo
2. Import as a new Vercel project
3. Your existing R Alpha site is untouched

Works on mobile and desktop. Everything client-side.
